## 25.3.20
- [x] `模板`可配置审批流程自动化，勾选后，系统根据当前步骤自动选择下一步（无需人为选择）
- [x] 接入钉钉（支持自动登录）
    - [x] `Account（账号）`增加`cid`字段（绑定企业）：`ALTER TABLE account ADD cid INTEGER;`
- `模板`可配置为极简流程：
    - [x] 增加`极简审批流`字段，可按顺序选择用户（一组）：`ALTER TABLE flow ADD chains TEXT;`
    - [x] 开启`极简审批`则无需选择处理步骤，自动关联到相关人员
    - [x] 适配`极简审批`
- [x] `流程数据/ProcessData`增加`status`字段（与流程同步）：`ALTER TABLE processData ADD status INTEGER;`
