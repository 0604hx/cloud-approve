## 自定义按钮/Button

定制页面中按钮分为两种：全局按钮（显示在检索区）、数据行按钮（仅限表格行内），其点击回调函数参数有差异：

**全局按钮**

参数为：btn/按钮对象（响应式），form/当前表单值（响应式），api/封装接口

```js
//示例：导出数据
if(!form.GT_addOn)
    return M.warn(`请选择起始日期`)
//查询数据并导出到 CSV 文件
api.query(form, btn).then(list=>{
    let rows = [["日期","请款人","付款金额","摘要"]]
    list.forEach(({ addOn, value })=>rows.push([ H.date.datetime(addOn), value.username, value.money, value.summary ]))
    H.io.saveToCSV(rows, `请款记录导出-${H.date.date()}`)
})
```

**数据行按钮**

参数为：row/当前行数据（属性 value 为业务数据），rowIndex/行序号，api/封装接口

```js
//示例：弹窗给用户输入支付金额，然后更新数据行
let { paied = 0, pays = [] } = row.value
let message = null
if(paied){
    message = `<b>已支付${paied}</b><br>${pays.map((p,i)=>`<div>${i+1}、${p}<div>`).join("")}`
}
M.prompt(`支付`, {placeholder:'请输入支付金额', type:"number", message }).then(v=>{
    if(v<=0)
        return M.warn(`请输入正数金额`)
    
    let payOn = H.date.date()
    paied+=v
    pays.unshift(`${payOn} 支付 ${v} 元`)
    api.update(row, { paied, pays, payOn }, { message:`支付信息录入成功` })
})
```
